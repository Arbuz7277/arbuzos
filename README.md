# ArbuzOS

**ArbuzOS** — это 32-битная операционная система, написанная с нуля на архитектуре x86, загружаемая через MBR. Этот проект был создан ради интереса и обучения.

## Требования
Для сборки проекта требуется:
* `nasm`
* `gcc`
* `make`

## Запуск
Чтобы запустить ArbuzOS на своем ПК, следуйте шагам:
1. Склонируйте репозиторий `git clone https://github.com/Arbuz7277/arbuzos.git` и перейдите в папку проекта.
2. Соберите проект `make`
3. Полученный образ `arbuzos.img` запустите на своем эмуляторе либо загрузите на флешку с помощью dd или Rufus и загрузитесь с нее. Убедитесь что при загрузке с флешки в BIOS включен режим Legacy (MBR), а не UEFI.
